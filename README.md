# 🏨 Agente Conversacional Hotelero (CIVA 2026)

## 📖 Descripción del Proyecto
Chatbot 24/7 multilingüe diseñado para el sector hotelero. Automatiza la atención al cliente, gestiona reservas de restaurante y canaliza solicitudes de mantenimiento mediante flujos lógicos.

## 🛠️ Stack Tecnológico
- **Frontend:** Next.js + Tailwind CSS
- **Automatización (Cerebro):** n8n
- **Base de Datos:** PostgreSQL (Supabase)
- **IA:** Modelo LLM para procesamiento natural
- **Despliegue:** Vercel
